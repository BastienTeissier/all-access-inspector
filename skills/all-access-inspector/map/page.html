Access map

Roles shows each capability against each role. Routes lists every endpoint with the checks it passes through, in order. How it's built says where each fact comes from. Alerts collects what to look at first.

Built by map build from tools/access-inspector/inventory.json and reviews.jsonl, the stack's tools/access-map/runtime.json, and the hand-written tools/access-map/vocabulary.json. A snapshot of the commit it was built from: decisions are recorded with map decide, not here.
